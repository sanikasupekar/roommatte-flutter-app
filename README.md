# Room Hive – Student Roommate Matching App

## About the Project
Room Hive is a Flutter-based mobile application designed to help students find compatible roommates based on their lifestyle preferences.

The application compares user preferences and calculates compatibility scores to recommend the top 5 matching roommates.

## Features
- User login using Firebase Authentication (Gmail).
- Store and manage user data using Firebase Realtime Database.
- Match roommates based on lifestyle preferences.
- Calculate compatibility percentages using Cosine Similarity.
- Display the top 5 roommate matches in descending order of compatibility scores.

## Technologies Used
- **Frontend:** Flutter
- **Authentication:** Firebase Authentication
- **Database:** Firebase Realtime Database
- **Matching Algorithm:** Cosine Similarity

## How It Works
1. Students enter their lifestyle preferences, such as cleanliness and sleeping schedules.
2. Preferences are converted into numerical vectors.
3. Cosine Similarity is used to calculate compatibility scores.
4. The application ranks the matches based on their scores.
5. The top 5 compatible roommates are displayed to the user.
